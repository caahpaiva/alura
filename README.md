# 🎓 Exercícios e Projetos — Alura

Repositório com projetos práticos desenvolvidos durante cursos da Alura, cobrindo testes automatizados, consumo de APIs e lógica de aplicação em Python.

## Projetos incluídos

### `bytebank-tdd`
Prática de Test-Driven Development (TDD) em Python — desenvolvimento guiado por testes automatizados, cobrindo escrita de testes antes da implementação e ciclos de refatoração.

### `modulo_api`
Exercícios de construção e consumo de APIs REST em Python, incluindo requisições HTTP e manipulação de dados retornados.

### `sabor_express_alura`
Projeto prático em Python simulando um sistema de pedidos, aplicando lógica de programação e estruturação de dados.

### `curso-python-2-aula_5`
Exercícios do módulo 2 do curso de Python, com foco em consolidação de fundamentos da linguagem.

## Tecnologias

- Python
- Testes automatizados (TDD)
- APIs REST

## Objetivo

Consolidar fundamentos de Python aplicados a boas práticas de desenvolvimento: testes, modularização e integração de sistemas — parte da minha preparação contínua para Data/Analytics Engineering.
